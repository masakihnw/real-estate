# 10年後の値上がり率と資産性の試算方法

この文書は、レポートに表示される10年後の推定価格、騰落率、資産性ランク（S/A/B/C）、推定含み益の計算方法をまとめたものです。
計算式と係数の正本でもあります。コードの呼び出し構成と入出力は [price-prediction-logic.md](./price-prediction-logic.md) を参照してください。

2026年1月時点の経済予測（日銀利上げ、賃料急騰、建築費高騰）に基づき、楽観・中立・悲観の3シナリオで10年後価格を算出します。
収益還元法と原価法で価格を出し、6対4で加重平均した値が最終価格のもとになります。

---

## 共通の前提

- 現在の推定成約価格は、掲載価格（売り出し価格）に売り出しから成約への補正係数0.958をかけた値です。この価格で購入したとみなして10年後を試算します。
- ローンは50年変動金利、金利1.2%、頭金ゼロで借りた想定です。
  10年後のローン残高を計算し、含み益、資産性、レポートの月額表示で共通に使います（`shared_utils.py` の `LOAN_ANNUAL_RATE`、`loan_calc.py` の `ANNUAL_RATE_VARIABLE`）。
- 騰落率、含み益、資産性には、中立（neutral）シナリオの価格をStandardとして使います。楽観はBest、悲観はWorstに対応し、参考表示にだけ使います。

---

## 1. 10年後の値上がり率（騰落率）

### 意味

現在の推定成約価格と10年後のStandard予測価格を比べた増減を、百分率で表した値です。

### 計算式

```
騰落率（%） = ( 10年後Standard価格 ÷ 現在の推定成約価格 − 1 ) × 100
```

- プラス（例 +5.2%）は、10年後に価格が上がる見込みを表します。
- マイナス（例 -8.6%）は、10年後に価格が下がる見込みを表します。

レポートの「騰落: -8.6%」は、この計算結果をそのまま表示しています。

### 10年後価格の決め方

`future_estate_predictor.py` の `FutureEstatePredictor` が、次の2つの方法で10年後価格を計算します。
両方の価格が正のときの10年後価格は、収益還元価格×0.6と原価法価格×0.4の合計です。
片方だけが正のときの10年後価格は、その価格です。

#### (A) 収益還元法

将来の家賃と金利から理論価格を算出します。

- 式は `Price_10y = (現行賃料×12 × (1+R_rent)^10) / (CapRate_base + (R_interest × β_area))` です。
- R_rent は、シナリオの家賃上昇率にエリア係数をかけた値です。エリア係数はS=1.2、A=1.0、B=0.9、C=0.8です。区ごとの賃料成長ポテンシャル（S/A/B/C）は `data/ward_potential.csv` の `rent_growth_potential` に定義しています。
- R_interest は、シナリオの10年後金利から現在金利（1.2%）を引いた値です。金利が上がるとキャップレートが上がり、価格は下がります。
- β_area はエリアの金利感応度で、S/Aが0.8、B/Cが1.2です。
- CapRate_base は、S=3.5%、A=4%、B=4.5%、C=4.5%です。

現行賃料が入力されていないときは、キャップレートを使って逆算します。
`price_predictor.py` 経由の月額賃料は、掲載価格×キャップレート÷12です。
キャップレートは `ward_coefficients.csv` の賃料成長グループから決めます（グループ1と2が3.5%、グループ3が4%、グループ4と5が4.5%）。
`FutureEstatePredictor` を単独で呼ぶ場合は、成約推定価格に上記のCapRate_baseをかけて年額賃料を求めます。

#### (B) 原価法

建築費の高騰で建物価値が下がりにくい状況を反映します。

- 式は `Price_10y = (土地価格×1.05) + (建物価格×(1−減価)×(1+R_const)^10)` です。
- R_const は、シナリオの建築費上昇率です。現在の推定成約価格を、土地65%、建物35%で按分します。
- 減価は年1.2%を10年分かけた12%です。築10年以内かつ総戸数200戸以上の場合は、減価を0にします。
- 区ごとの供給制約（`ward_potential.csv` の `supply_constraint`）を価格にかけます。新築供給が少ない区ほど係数が大きく、中古価格は高く維持される想定です。

#### (C) 2026年市場補正

次の3つの補正を、加重平均した価格へ順にかけた結果が最終価格です。

1. 15分ずらしボーナス +5%。江東区、墨田区、品川区で、駅徒歩5分以内の物件が対象です。都心まで15分という立地を想定しています。
2. 在庫調整ペナルティ -5%。港区、中央区、千代田区で、補正途中の10年後価格が1.5億円以上の物件が対象です。
3. 省エネ・リノベ優遇 +2%。備考や特徴の文章にZEH、省エネ、断熱、リノベーション済、リフォーム済のいずれかを含む物件が対象です。築年が古くても、住宅ローン控除の拡充を反映して加算します。

#### 3シナリオの既定値（2026年予測ベース）

| シナリオ | 家賃上昇率 | 10年後金利 | 建築費上昇率 | レポート対応 |
|----------|------------|------------|--------------|--------------|
| 楽観 (optimistic) | 年4% | 1.5% | 年5% | Best |
| 中立 (neutral) | 年2% | 2.5% | 年3% | Standard |
| 悲観 (pessimistic) | 年0.5% | 4% | 年1% | Worst |

`FutureEstatePredictor(macro_scenarios={...})` で、これらの数値を差し替えられます。定義は `future_estate_predictor.py` の `DEFAULT_MACRO_SCENARIOS` にあります。

## 2. 資産性ランク（S/A/B/C）

### 意味

10年後にローンを返済したあとの含み益が、購入価格に対してどれだけ残るかを比率（含み益率）で表した値です。
その大きさで4段階に分けた指標です。

### 計算の流れ

#### 手順1 含み益と含み益率を求める

- 10年後のローン残高は、現在の推定成約価格を借りたと想定した、10年後時点の残債です。
  借入条件は50年、金利1.2%、元利均等、頭金ゼロです。
- 含み益（円）は `10年後Standard価格 − 10年後ローン残高` です。10年後に売却してローンを返した後に残る金額で、マイナスならオーバーローンです。
- 含み益率（%）は `含み益 ÷ 現在の推定成約価格 × 100` です。

#### 手順2 含み益率でランクを決める

| 含み益率 | 資産性ランク | 意味 |
|----------|--------------|------|
| 10%以上 | S | 購入価格の1割以上が含み益になる見込み |
| 5%以上10%未満 | A | 5〜10%程度の含み益が見込める |
| 0%以上5%未満 | B | 含み益は少ないが、オーバーローンではない見込み |
| 0%未満 | C | 10年後時点でローン残高が時価を上回る可能性がある（オーバーローン） |

ランクの判定は `price_predictor.py` の `implied_gain_ratio_to_asset_rank` が行い、`asset_score.py` が呼び出します。レポートの「資産性根拠: 含み益率+20.3%」には、この含み益率を表示します。

`FutureEstatePredictor` の戻り値にある `investment_grade` は、含み益率20%以上でS、12%以上でA、5%以上でB、それ未満でCです。この値は `price_predictor.py` の `profit_level`（高・中・低）の判定と戦略アドバイス文に使い、レポートの資産性ランクには使いません。

### 式のまとめ

```
現在の推定成約価格 = 掲載価格 × 0.958
10年後Standard価格   = 収益還元法×0.6 + 原価法×0.4 に2026年市場補正を適用（中立シナリオ）
10年後ローン残高     = 成約価格を50年・1.2%・元利均等で借りたときの10年後残債

含み益（円） = 10年後Standard価格 − 10年後ローン残高
含み益率（%） = 含み益 ÷ 現在の推定成約価格 × 100

資産性ランク = 含み益率で S(≥10%) / A(≥5%) / B(≥0%) / C(<0%)
```

## 3. レポート表示との対応

| レポートの表示 | 中身 |
|----------------|------|
| 10年後の推定価格 | 10年後Standard価格（万円表示） |
| 騰落率（例 騰落:-8.6%） | `(10年後Standard価格 ÷ 現在成約価格 − 1) × 100` |
| 推定含み益（例 +1349万円） | `10年後Standard価格 − 10年後ローン残高`（万円） |
| 資産性(S/A/B/C) | 含み益率によるランク（S≥10%, A≥5%, B≥0%, C<0%） |
| 資産性根拠（例 含み益率+20.3%） | 上記の含み益率（%） |

騰落率と資産性は、同じ現在の推定成約価格と10年後Standard（中立）価格から計算します。計算は `price_predictor.py` が `FutureEstatePredictor` を呼んで行い、`asset_score.py` も同じ結果を使います。

---

## 4. 3シナリオ（Standard / Best / Worst）

- Standardは中立シナリオ（賃料上昇年2%、10年後金利2.5%、建築費年3%）です。騰落率、含み益、資産性はすべてこの価格から計算します。
- BestとWorstは、楽観シナリオと悲観シナリオに対応します。賃料、金利、建築費の前提が異なります。騰落率、含み益、資産性ランクには使わず、3シナリオの表に参考として表示します。

詳細は `future_estate_predictor.py` と `price_predictor.py` を参照してください。

レポート（`generate_report.py`）とSlack通知（`slack_notify.py`）は、3シナリオを `optional_features.get_three_scenario_columns` から取得します。この関数が使えないときは "-" を表示します。
