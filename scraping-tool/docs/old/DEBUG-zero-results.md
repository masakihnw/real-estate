# 取得件数が0件のときの確認方法

取得件数が0件になる原因は、次の2つです。

## 1. 一覧ページのHTML構造が変わった（パース0件）

SUUMOやHOME'Sの一覧ページのクラス名やレイアウトが変わると、パース結果が0件になります。

ログの例は次のとおりです。

- `SUUMO: sc_XX ページN パース0件 (HTML: NB, 連続: n/2) — botブロック/構造変更の可能性、次ページへ進みます`
- `HOME'S: セレクタが0件 — HTML構造が変わった可能性があります。`
- `HOME'S: ページNでパース0件 (HTML: NB, 連続: n/2) — 次ページへ進みます`

0件パースが連続2回続くと、SUUMOはその区、HOME'Sは一覧全体の取得を打ち切ります。HOME'Sで全ページが0件だった場合は、異常応答のHTMLが `data/debug_dumps/` に保存されます。

確認の手順は次のとおり。

- フィルタを外して実行し、生データが取れるか確認します。
  ```bash
  python main.py --source suumo --no-filter -o /tmp/suumo_raw.json
  python main.py --source homes --no-filter -o /tmp/homes_raw.json
  ```
- どちらも0件なら、該当サイトの一覧HTMLを開き、SUUMOの `property_unit-content` と `cassetteitem`、HOME'Sの `mod-mergeBuilding` などのセレクタがまだ使えるかを確認します。

## 2. 全件が条件で除外された（パースはできているが通過0件）

価格、専有面積、間取り、築年、徒歩、東京23区のいずれかの条件で、パースした物件がすべて除外された場合です。

ログの例は次のとおりです。

- `SUUMO: sc_XX 早期打ち切り（20ページ連続で通過0件, 累計通過: N件）`
- `HOME'S: 早期打ち切り（20ページ連続で通過0件, 累計通過: N件）`

確認の手順は次のとおり。

- 上記と同様に `--no-filter` で実行し、生データに物件が含まれているか確認します。
- `config.py` の条件（価格帯、専有面積、築年、徒歩、東京23区）を見直します。

## まとめ

| ログ | 原因 |
|------|------|
| 「パース0件」「セレクタが0件」 | 一覧のHTML構造が変わった、またはbotブロック。サイトの一覧ページを確認し、必要ならセレクタを修正する。 |
| 「早期打ち切り（Nページ連続で通過0件）」 | 条件が厳しすぎる、または住所とURLの判定で23区以外が混ざっている。`--no-filter` で生データを確認し、条件を調整する。 |
