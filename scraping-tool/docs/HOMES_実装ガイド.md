# HOME'S 一覧ページのHTML取得手順

HOME'Sの一覧ページは、サイト側の変更でパースが0件になることがあります。原因を調べるには、検索結果一覧のHTML、検索URL、物件カードの構造が必要です。この文書は、それらを取得して共有する手順をまとめます。

## 現在の実装

`homes_scraper.py` は実装済みです。

- `parse_list_html()` は、一覧HTMLから `HomesListing` のリストを返します。JSON-LDのItemListと、HTMLの `mod-mergeBuilding--sale` および `mod-listKks` のブロックを両方読みます。
- `scrape_homes()` は、Playwrightで東京23区の一覧ページを取得し、`HomesListing` をyieldします。Playwrightが未インストールなら、警告を出して何も返しません。
- テストは `tests/test_homes_scraper.py` にあります。

パース結果が0件になったときは、次の手順でHTMLを取得し、`parse_list_html()` のセレクタと照らして修正します。

---

## 方法1 開発者ツールでHTMLを取得する（推奨）

### 手順

1. HOME'Sで中古マンション検索を実行します。
   - https://www.homes.co.jp/mansion/chuko/ にアクセスします。
   - 条件を設定します（例: 関東、駅徒歩5分以内、価格 7500万〜1億）。
   - 検索結果一覧ページを表示します。

2. 開発者ツールを開きます。
   - WindowsとLinuxでは `F12` または `Ctrl+Shift+I` を押します。
   - Macでは `Cmd+Option+I` を押します。
   - ページ上で右クリックし、「検証」（Inspect）を選んでも開けます。

3. HTMLをコピーします。
   - 開発者ツールの「Elements」タブ（日本語表示では「要素」タブ）を開きます。
   - `<html>` タグを右クリックします。「Copy」から「Copy element」または「Copy outerHTML」を選びます。
   - `<body>` タグだけをコピーしてもかまいません。

4. ファイルに保存して共有します。
   - コピーしたHTMLをテキストファイル（例: `homes_list_sample.html`）に保存します。
   - そのファイルを共有するか、内容を貼り付けます。

### 必要な情報

- 検索URLは、ブラウザのアドレスバーに表示された完全なURLです。例は `https://www.homes.co.jp/mansion/chuko/tokyo/city/?...` です。
- HTMLは、上記の手順で取得したものです。全体でなくても、物件カード部分だけで足ります。

## 方法2 スクリーンショットとURL

### 手順

1. 条件を設定して検索し、一覧が表示された状態でスクリーンショットを撮ります。
2. ブラウザのアドレスバーから完全なURLをコピーします。
3. スクリーンショットとURLを共有します。

スクリーンショットだけでもHTML構造は推測できますが、正確な修正にはHTMLが必要です。可能なら方法1を使ってください。

---

## 方法3 文章で説明する

次の情報だけでも、修正の方向は決まります。

1. 検索URLの形式
   - 例: `https://www.homes.co.jp/mansion/chuko/tokyo/city/` のような形式か。
   - `?` 以降のパラメータで条件を指定する形式か。

2. 物件カードの見た目
   - 一覧ページで1件の物件がどう表示されているかを、文章で説明してください。

3. ページネーション
   - 「次へ」ボタンがあるか。
   - `?page=2` などのURLパラメータでページを切り替えるか。

## 調べる項目

### 1. 検索URLの構造

次の条件で検索したとき、URLがどうなるかを確認します。

- エリア: 関東（または東京）
- 駅徒歩: 5分以内
- 価格: 7500万〜1億円（指定できる場合）
- 専有面積: 55〜75㎡（指定できる場合）
- 間取り: 2LDK〜3LDK（指定できる場合）

SUUMOのURLは次の形式です。

```
https://suumo.jp/jj/bukken/ichiran/JJ012FC001/?ar=030&bs=011&hd=S3ksl000&tm=S3ksl000&pc=100
```

### 2. 物件カードのHTML構造

一覧ページで、1件の物件がどのタグで囲まれているかを確認します。SUUMOの例は次のとおりです。

```html
<div class="property_unit-content">
  <dt>物件名</dt>
  <dd>マンション名</dd>
  <dt>販売価格</dt>
  <dd>7699万円</dd>
  ...
</div>
```

### 3. 各項目の取得方法

次の項目について、HTML上の表現を確認してください。

- 物件名は、どのタグとクラス名に含まれているか。
- 価格は、「販売価格」や「価格」のラベルがあるか。クラス名は何か。
- 所在地は、どのタグに含まれているか。
- 駅と徒歩は、「最寄駅」や「徒歩○分」がどの形式で書かれているか。
- 専有面積は、「専有面積」や「55.5m²」がどの形式で書かれているか。
- 間取りは、「2LDK」や「3LDK」がどの形式で書かれているか。
- 築年は、「築年月」や「1982年」がどの形式で書かれているか。
- 詳細URLは、物件詳細ページへのリンクがどこにあるか。

## 最も簡単な方法 HTMLファイルを1つ共有する

1. HOME'Sで中古マンション検索を実行します（条件は任意です）。
2. 検索結果一覧ページを表示します。
3. ページ全体を保存します。
   - Windowsでは `Ctrl+S` を押し、「ウェブページ、完全」で保存します。
   - Macでは `Cmd+S` を押し、「ウェブアーカイブ」または「ページソース」で保存します。
4. 保存したファイル（`.html` または `.mhtml`）を共有します。

このファイルがあれば、URL、HTML構造、セレクタをすべて確認できます。
