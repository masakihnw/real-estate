# Slack通知と東京23区フィルタの修正（2026-01-30）

2026-01-30の修正記録です。関数名とファイル名は修正当時のもので、現在の配置は各節の末尾に書いています。

## 起きていたこと

1. 前回から変更がなさそうなのにSlackが送られていました。
   変更検知がURL基準だったため、同じ物件がSUUMOとHOME'Sで別URLで出ると、毎回差分と判定されました。例えば「7件削除・7件新規」と判定され、通知が飛んでいました。

2. 東京23区以外の物件が送られていました。
   過去の `latest.json` に、神奈川など他県の物件（例: デイパーク横濱天王町）が含まれていました。SUUMOは東京都一覧から取得していますが、URLに `/kanagawa/` などを含む物件を除外していませんでした。
また、住所が空の物件をすべて除外していました。このため、住所のパースに失敗すると、東京23区の物件まで0件になる可能性がありました。

3. 対象件数0件で「削除7件」の通知が来ていました。
   上記の結果、現行の取得が0件（または住所パースで全件除外）のときに、「削除7件」だけの通知が送られていました。

## 対応内容

### 1. 変更検知を物件キーで行う

- `generate_report.py` に `listing_key(r)` を追加しました。名前、間取り、専有面積、価格、住所、築年、駅徒歩で一意のキーを作ります。`compare_listings()` は、このキーで比較するように変更しました。
- `check_changes.py` も同じ `listing_key` で、currentとpreviousを比較するようにしました。同じ物件が別URL（SUUMOとHOME'S）で出ても、同一とみなします。
- `main.py` は、重複除去に `generate_report.listing_key` を使うようにしました。キーの定義を1か所に統一するためです。

これにより、実質同じ物件のURLだけが変わった場合は差分なしと判定され、不要なSlack通知は出なくなる。

現在の配置は次のとおりです。`listing_key` と `compare_listings()` は `report_utils.py` にあり、`generate_report.py` と `main.py` はそこから読み込みます。`compare_listings()` と `check_changes.py` が同一物件の判定に使うキーは `identity_key` です。価格、駅名、徒歩分数を含まないため、価格だけが変わった物件は更新として扱われます。

### 2. 東京23区フィルタの強化（SUUMO）

- `config.py` に `NON_TOKYO_23_URL_PATHS` を追加しました（`/kanagawa/`、`/chiba/`、`/saitama/` など）。
- `suumo_scraper.py` の判定を `_is_tokyo_23(address, url)` に変更しました。
  - URLに他県のパスが含まれる場合は除外します。
  - 住所に23区の区名が含まれる場合は採用します。
  - 住所が空でも、URLに `/tokyo/` が含まれる場合は採用します。一覧の住所パースに失敗したときの救済です。

神奈川などの物件はURLで除外され、住所が取れない東京の物件もURLが `/tokyo/` なら残るようになりました。現在の `_is_tokyo_23` は、区ごと一覧から取得した行をその区の物件とみなす判定も持ちます。

### 3. ワークフロー（コミットメッセージ）

コミットメッセージの取得件数は、`latest.json` の件数から取得するように変更しました。以前の取得元は、削除済みの `current_*.json` でした。現在は `.github/workflows/enrich-and-report.yml` の Commit and push ステップが、`jq length scraping-tool/results/latest.json` で件数を求めています。

## 運用上の注意

- 初回、または23区フィルタの導入後に、既存の `latest.json` に他県の物件が含まれている場合があります。その物件は次回の実行で、「削除」としてレポートとSlackに出ます。
  これが1回だけ出れば正常です。
- 取得が0件のときは、削除だけの差分になります。当時は「削除のみ」の通知が送られる場合がありました。現在の `slack_notify.py` は、新規が無く削除だけの差分では、AIダイジェストと注目物件の値下げが無い限り、通知を保留します。
- SUUMOやHOME'Sのページ構造が変わって住所が取れないと、0件になる可能性があります。その場合も、URLによる救済で東京の物件が残るようにしてあります。
