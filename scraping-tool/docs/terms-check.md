# 各サイトの利用規約確認結果

スクレイピングツールの実装可否を判断するため、対象サイトの利用規約を確認した結果をまとめる。確認日は2025年で、具体的な日付は記録していない。規約は変更されるため、利用前に必ず公式ページで最新版を確認すること。

---

## 1. SUUMO（スーモ）

### 規約の場所

- ご利用規約 https://cdn.p.recruit.co.jp/terms/suu-t-1003/index.html
- 規約一覧 https://suumo.jp/edit/kiyaku/
- 物件情報の取扱いについて https://suumo.jp/edit/privacypolicy/bukken.html

### スクレイピング・自動取得に関する記載

| 条文 | 内容 | スクレイピングとの関係 |
|------|------|------------------------|
| 第2条（著作権等） | 本サイトのコンテンツについて、当社の事前の承諾なく著作権法で定めるユーザー個人の私的利用の範囲を超える使用をしてはならない。 | 私的利用の範囲内であれば、条文上は許容の余地がある。ただし「使用」に自動取得と蓄積が含まれるかは解釈次第。 |
| 第3条（禁止行為）(6) | 本サイトの運営を妨げる行為をしてはならない。 | 短時間の大量アクセスなど、サーバー負荷や運営を妨げる行為は禁止。間隔を空けた軽いアクセスかどうかが論点になる。 |
| 第3条（禁止行為）(7) | 商業目的で利用する行為（当社が認める場合を除く）をしてはならない。 | 個人の住まい探しや資産検討のための利用は、商業目的に当たらない解釈も可能。ツールを第三者に販売・提供する場合は、商業目的になりうる。 |

### クローラー・スパイダー等の明示的禁止

- クローラー・スパイダーを明示的に禁止する条項はない。
- ただし、無制限の自動収集は、次の項目と組み合わせるとリスクがある。(6)運営妨害、(7)商業目的、第2条の私的利用の範囲を超える使用である。

### 運用上の注意（スクレイピングを行う場合）

- 私的利用（自分用の物件候補リスト作成）にとどめ、転売・再配布・営利利用は行わない。
- 負荷を抑える。リクエスト間隔を1〜2秒以上にし、同時接続数を抑え、キャッシュを活用する。
- User-Agentを適切に表示し、必要に応じて問い合わせ先を明記した運用説明を用意する。
- 規約改定で自動アクセス禁止などが追加される可能性があるため、利用前に都度規約を確認する。

## 2. at home（アットホーム）

### 規約の場所

- 利用規約 https://www.athome.co.jp/help/kiyaku.html
- スマートフォン向け https://www.athome.co.jp/smt/athome/kiyaku.html

### スクレイピング・自動取得に関する記載

| 条文 | 内容 | スクレイピングとの関係 |
|------|------|------------------------|
| 第4条（禁止事項）(7) | 通常の範囲でのWebブラウザによる使用以外での特殊なアクセス行為、その他本サイトの運営・提供若しくは他の利用者による本サイトの利用を妨害し、又はそれらに支障をきたす行為。 | プログラムによる自動アクセスは、特殊なアクセスに該当しうる。 |
| 第4条（禁止事項）(11) | アットホームが許諾した方法以外で、本サイト又は本サイトに掲載された情報・サービスを自らまたは第三者を利用して商業（営利）目的で利用する行為。 | 許諾外の営利目的の利用は禁止。 |
| 第4条（禁止事項）(13) | クローラー、スパイダー及びこれらに類似するプログラムや処理技術等を用いて本サイトの情報を取得する行為。 | クローラー・スパイダー等による情報取得を明示的に禁止している。 |

### クローラー・スパイダー等の明示的禁止

- 第4条(13)が、クローラー・スパイダーおよびこれらに類似するプログラム等を用いた情報取得を明示的に禁止している。
- 目的（私的か商業か）や負荷の大小を問わず、規約上は自動収集行為そのものが禁止と解釈するのが自然である。

### 結論（at home）

- スクレイピングツールによるat homeからの情報取得は、利用規約に照らして推奨できない。
- 利用する場合は、ブラウザで手動検索し、結果を自分でメモ・保存する程度にとどめるほうが、規約リスクは小さい。
- リポジトリには `athome_scraper.py` があるが、`config.py` の `DISABLED_SCRAPERS` で無効にしている。無効にした理由は、GitHub ActionsのIPがbot判定を受け、全区で0件になるためである。この規約確認の結果とは別の理由である。

### スクレイピング・自動取得に関する記載

| 条文 | 内容 | スクレイピングとの関係 |
|------|------|------------------------|
| 第6条（利用者の権利について）1項 | 本サービス及びサイトに関するコンテンツ等について、著作権法その他法令で認められている場合を除き、当社および権利者に無断で使用、複製、翻案、改変、転載、配布、公開、公衆送信等を行うことはできません。 | 私的利用や引用など、法令で認められる範囲を超える利用は禁止。自動収集が複製や公衆送信等に当たるかは解釈次第。 |
| 第16条（禁止行為等）(6) | 本サービスの利用又は提供を妨げる行為をしてはならない。 | 過度なアクセスは、提供を妨げると判断されうる。 |
| 第16条（禁止行為等）(9) | 本サービスを利用した営業活動その他営利を目的とする行為をしてはならない。 | 営利目的の利用は禁止。 |
| 第16条（禁止行為等）(14) | 本サービスを通じて利用者に対して提供される情報を第三者に提供する行為（本サービスを通じて利用者にのみ提供された情報に限る）。 | 取得した情報の第三者提供は禁止。 |
| 第16条（禁止行為等）(15) | その他、当社が不適切と判断する行為。 | 規約に明示のない自動収集も、不適切とされる余地がある。 |

### クローラー・スパイダー等の明示的禁止

- 「クローラー」「スパイダー」などの語による明示的な禁止条項はない。
- その代わり、自動で大量に情報を取得して転用する行為は、禁止の範囲に入りうる。該当しうる項目は、(6)妨害行為、(9)営利目的、(14)第三者提供、(15)不適切な行為などである。

### 運用上の注意（スクレイピングを行う場合）

- at homeほど一律に禁止とは書かれていないが、無許諾の自動収集は、規約とリスクの両面で推奨されない。
- 利用する場合は、(6)(9)(14)(15)に触れないよう、私的利用、軽い負荷、第三者への提供なしを徹底する。可能であれば、利用前に運営者への問い合わせを検討する。

## 4. REINS取引価格情報（レインズマーケットインフォメーション / contract.reins.or.jp）

### サイト

- 不動産取引情報提供サイト（指定流通機構が取引価格情報を提供）
- URL https://www.contract.reins.or.jp/
- 検索時点では、直接の規約ページの取得と所在の特定ができていない。以下は要確認として記載する。

### 確認できたこと

- 一般消費者向けに、成約価格等の検索が無料で提供されている旨の説明が、各種記事等にある。
- 一方で、contract.reins.or.jp上の利用規約やご利用条件等の全文は確認できていない。サイト構造やJavaScriptなどの理由で取得できなかった可能性がある。

### スクレイピング・自動取得について

- 規約上のクローラー禁止や自動取得禁止の有無は未確認である。
- 指定流通機構・REINS関連の一次情報として、次の確認を推奨する。
  1. サイト内の利用規約やご利用条件等のリンクから、最新の利用規約を入手する。
  2. 規約中に、自動アクセス・爬虫行為・データの二次利用に関する記載がないかを確認する。
  3. 不明な点は、指定流通機構またはサイトに記載のお問い合わせ先に確認する。

### 結論（REINS取引価格情報）

- 現時点では、規約上スクレイピングできるかを断定できない。
- ツールで自動取得する前に、公式の利用規約を必ず確認し、必要なら運営者に問い合わせることが望ましい。
- 規約で禁止されている場合や、回答が得られない場合は、運用を次の範囲にとどめるのが安全である。ブラウザでの手動検索と、必要に応じた手動のメモ・保存である。

## 6. 実装判断への反映（feasibility-studyとの関係）

- at homeは、規約上、クローラー等による情報取得が禁止されている。このため、スクレイピングの対象から外すことを推奨する。
- SUUMOについては、規約上ある程度の合理性があると解釈できる。対象は、私的利用と軽負荷に限定した一次フィルタ用のスクレイピングである。
  リスクを理解したうえで対象に含める場合は、負荷対策、利用目的の明確化、規約の定期確認が前提になる。
- HOME'Sは、明示的な禁止はないが、禁止行為のいずれかに当たりうる。このため、実装の優先度を低くするか、運営者に確認してから判断するのが無難である。
- REINS取引価格情報は、規約確認を先に実施する。禁止でなければ補助的な自動取得を行い、禁止または不明な場合は、手動検索と手動入力リストに役割を限定する。

この確認結果は、[feasibility-study.md](./feasibility-study.md) の第4節に反映した。第3.1節の「対象サイト」は、まだ更新していない。
