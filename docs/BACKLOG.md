# UI/UX 刷新 バックログ

このファイルは、`docs/UIUX_REDESIGN_PROPOSAL.md` の Phase 1〜5 を実装したあとに残った項目と、意図的に見送った項目を管理する。
Phase 1〜5 の中核は実装済みで、内容はタブ再編、今日タブ、AIブリーフ、保存フィルタ通知、スワイプ強化、ウィジェット、詳細5タブ、お金統合、ソート刷新、比較再設計、内見モード、地図フル刷新である。これらは main にマージされている。

## 管理方法

- 正本: 本ファイル（`docs/BACKLOG.md`）。項目の状態はここだけに書く。提案書の §5（追加機能 P1〜P3、削除・縮小の提案）から派生した。
- 運用: 着手時に該当項目の「状態」列を `進行中` にし、完了したら `済 (PR #xx)` と書く。粒度が大きい項目や期日を管理したい項目は、着手時に GitHub Issue へ昇格し、本ファイルからリンクする。
- 優先度の目安: P2（次フェーズ）、縮小提案の未実施、P3（新規データ取得が必要）の順。運用・手動確認はリリース前チェックとして別に管理する。
- 同期: 提案書を改訂したら本ファイルも更新する。完了項目は履歴として残し、消さない。
